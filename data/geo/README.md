# 서울 행정경계 (GeoJSON)

| 파일 | 내용 | 피처 |
|---|---|---|
| `seoul_municipalities_simple.json` | 자치구 경계 | 25 |
| `seoul_neighborhoods_simple.json` | **법정동** 경계 | 467 |

- 출처: https://github.com/southkorea/seoul-maps — `juso/2015/json/`
- 원자료: 행정안전부 도로명주소 사업의 법정구역 경계 (2015)
- 받은 날: 2026-09-11
- `_simple` 은 폴리곤을 단순화한 판이다. 지도 표시에는 충분하고 가볍다.
  정밀 면적 계산이 필요하면 원 저장소의 단순화 안 된 판을 받아야 한다.

## 왜 이 자료인가

공개된 서울 경계 자료는 대부분 **행정동**(住民센터 관할)이다. 우리는
**법정동**(땅 이름, 등기·지번의 기준)으로 처치를 배정하므로
([[../../docs/decisions/0010-지정범위-동전체-판정.md]]) 법정동 경계라야 한다.
`juso/2015` 는 도로명주소 사업 자료라 법정구역이고, 피처 수 467개가
서울 법정동 수와 일치한다.

## 거래 자료와 어떻게 잇는가

법정동코드 10자리의 **앞 8자리**가 이 자료의 `EMD_CD` 와 같다.

```
거래 자료  umd_full_cd = 1168010600   (대치동)
경계 자료  EMD_CD      =   11680106
```

이름이 아니라 코드로 잇는다. 실거래 자료에는 자치구와 법정동명이 어긋난
기록이 소수 있다(140만건 중 28건). `scripts/lib/geo.py` 가 이 결합과
행정동→법정동 정규화를 담당한다.
