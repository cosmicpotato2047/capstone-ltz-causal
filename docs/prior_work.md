### ① 전상현·김성용·박종선 (2025)
토지거래허가구역 지정이 아파트 가격에 미치는 영향에 관한 연구.
융합사회와 공공정책 19(1), 169-189. (가천대)

- 기간 2019.6.23~2021.6.23 (전후 각 12개월)
- 분석단위: **동-월 패널 675개 = 27개동 x 25개월**
- 종속변수: log(동-월 평균 ㎡당 거래금액)  <- 집계값
- 사양: OLS. 구역더미 + 시점더미 + 교호항 + **거래건수**. 고정효과 없음.
- 보고: Zone +0.3263 / Time +0.2724 / Zone#Time +0.2928(p=0.053) / n +0.0116 / R2 0.0757
- 결론 본문은 신중함: "거래건수 60% 이상 감소", "가격에는 영향을 주지 않았다"
  (초록은 상승으로 서술 — 본문보다 강함)

**재현 결과 (scripts/replicate_jeon2025.py)**
- 동일 격자 675개 재현. 거래 없는 빈 셀 31개, 전부 통제동
  (삼전동·석촌동·압구정동·율현동)
- 논문 기술통계의 가격 최소값 0, log 최소값 0 -> 빈 셀을 0으로 코딩한 것으로 보임
- 0 코딩 시:   Zone +0.3464 / Time +0.2334 / Zone#Time +0.3549 / n +0.0138 / R2 0.0804
  -> 네 계수와 R2 모두 논문값에 근사
- 빈 셀 정상 제외: Zone#Time **-0.0448** (p=0.221), R2 0.2496  <- 부호 반전
- 거래건수 통제 제거 시: -0.1121 (p=0.002).  + 동·월 FE: -0.1215
- 거래량 감소는 정책의 결과이므로 통제변수로 넣으면 bad control 문제

### ② 이한웅·이춘원 (2025)
토지거래허가구역 지정이 매매가와 전세가에 미치는 영향: 잠실동 아파트 사례분석.
대한부동산학회지 43(2), 161-180. (광운대)

- 처치: 잠실동 / 통제: **잠실동 제외 송파구 모든 동**

- 평행추세 가정 검증의 필요성을 본문에서 명시적으로 언급
- 결과: 거래량 급감 / 매매가 유의 상승 / 비허가지역이 더 크게 상승(풍선효과)
  전세가는 단기 무반응, 지정 2년 후부터 유의 상승
- 기여: **전세시장까지 확장**한 유일한 연구

### ③ 양지영·정준호 (2025)
토지거래허가구역 지정의 풍선효과 분석: 잠실·삼성·대치·청담동 사례를 중심으로.
한국콘텐츠학회논문지 25(5), 447-. DOI 10.5392/JKCA.2025.25.05.447 (강원대)

- 기간 2018.6~2022.5
- 처치 4개 법정동 / 대조 15개 법정동:

- 방법: **합성대조군법(SCM)**
- 종속변수: 동별 평균 가격의 로그 (가구당 평균 아파트 가격, 총액 기준)
- 예측변수: 세대수, 건축연도, 금리, 입주물량, 지하철역·백화점·학원가·공원 접근성(QGIS)

- 저자들이 복수 정책 중첩(재초환 2018.1, 분상제 2019.12, 규제지역 확대) 한계를 명시

- 대조군의 압구정동·성수1가동·성수2가동은 **2021.4.27 토허구역으로 지정됨**

  15개 대조군 중 3개(20%)가 처치를 받은 상태

## 처치 역전 (treatment reversal) 문헌 — 2026-09-03 추가 확인

**결론: 처치 역전은 새로운 설정이 아니다.** 초안의 "국내외 문헌에서 분석된 바 없다"는
철회한다.

- **de Chaisemartin & D'Haultfœuille (2020, AER 110(9))** Two-Way Fixed Effects
  Estimators with Heterogeneous Treatment Effects. 처치가 켜졌다 꺼지는
  비흡수 처치를 명시적으로 다루는 추정량. Stata `did_multiplegt`.
  <- 본 연구 2025 구간의 표준 도구
- Leary (2009) 은행 신용 공급의 확대(1961 CD 시장)와 축소(1966 신용경색)를
  연달아 이용한 고전적 처치 역전 사례
- 코로나 봉쇄 해제, 퇴거유예 종료 등 다분야 적용례
- 중국 주택구입제한 문헌에도 개별 도시의 취소·재긴축을 다룬 연구가 존재

**따라서 주장 가능한 범위는 다음으로 좁힌다.**
1. 역전 간격이 39일로 극히 짧다 (중국 사례는 도시 단위·수개월~수년)
2. 해제가 부분적이어서 같은 동 안에 규제 상태가 다른 단지가 공존한다
   (도시 단위 on/off 에서는 도시 내부에 비교군이 생기지 않는다)
3. 국내에서 2025년 사건을 분석한 연구는 확인되지 않았다 (발표 시차)

## 각 논문의 실제 결론 — 초록과 본문의 구분 (2026-09-03 정리)

초록만 보면 갈리지만 **본문 결과는 세 편 모두 같은 방향(억제)** 을 가리킨다.

### 전상현 외 (2025)
- 초록: "허가구역 거래가격이 비허가구역 대비 유의하게 상승, 정책 시행 후에도 유의하게 상승"
- 실제: 앞 절은 **Zone 계수(+0.326)** = 허가구역이 원래 비싸다는 수준 차이.
  뒤 절은 **Time 계수(+0.272)** = 시장 전반의 상승. 둘 다 정책 효과가 아니다.
  **초록은 이중차분 계수를 언급조차 하지 않는다.**
- DID 계수 Zone#Time = +0.293, **p=0.053 으로 5% 수준 비유의**
- 본문 결론: "거래건수 60% 이상 감소... 단위당 거래금액은 지역별로 차이가 없는 것으로
  나타났다... 아파트 가격에는 영향을 주지 않았다"  <- 정확한 서술
- 재현: 결측 정상 처리 시 -0.045(p=0.221), 거래건수 통제 제거 시 -0.112(p=0.002)

### 이한웅·이춘원 (2025)
- 초록: "지정 직후 거래량 급감, 매매가격 유의하게 상승"
- 실제: 보고된 t-검정은 **각 집단 내부의 사전-사후 비교**이며 DID 계수가 아니다.
- 본문: "주목할 점은, 잠실동보다 오히려 비잠실 지역에서 더 큰 폭의 가격 상승이
  관측되었다는 점이다"  <- 이 문장이 곧 DID 음수라는 뜻
- 논문 표로 DID 계산: +12.2 / -2.9 / -3.9 %p (±3 / ±6 / ±12개월)
- 본 연구 재현: +12.2 / -3.4 / -3.9 %p, ±36개월 -13.7%p. 거의 일치
- ±3개월 양(+)은 구성 변화. 단지 FE 적용 시 +8.2% -> -0.1% 로 소멸

### 양지영·정준호 (2025)
- 초록·본문 일치: 처치지역 상승 억제, 인근 지역 급등(풍선효과)
- 도너풀 오염(압구정·성수1가·성수2가가 2021.4 처치)의 방향은
  **억제 효과를 과소평가**하는 쪽. 통제군도 규제를 받으면 격차가 작아 보인다.

### 겉보기 불일치의 세 층위

1. **초록이 본문과 다르게 읽힌다** — 주효과를 정책 효과처럼, 절대 상승을 상대 상승처럼
2. **DID 계수를 명시적으로 제시하지 않는다** — 독자가 직접 빼야 알 수 있다
3. **그 위에 분석 문제가 얹힌다** — 결측 처리, 거래건수 통제, 도너풀 오염

**부호를 실제로 뒤집을 만큼 결정적이었던 것은 3번 중 결측 처리 하나뿐이다.**
따라서 이는 개별 논문의 결함이라기보다 **비교 대상을 명시하지 않는 서술 관행**의 문제로
다루는 것이 사실에 부합하고 프레이밍상으로도 안전하다.
