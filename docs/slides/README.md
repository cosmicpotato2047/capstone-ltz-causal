# 발표 자료 보관

각 발표일의 HTML 을 그대로 보관한다. 브라우저로 열면 바로 발표할 수 있고,
인터넷이 없어도 동작한다(웹폰트만 기본 글꼴로 대체됨).

- `←` `→` 키로 슬라이드 이동
- `Ctrl+P` 로 인쇄하면 슬라이드 한 장이 한 페이지가 된다 (PDF 저장용)
- 파일 첫 줄에 `<meta charset="utf-8">` 가 있어야 한다. 없으면 HTTP 로
  열 때 글자가 깨진다 (2026-10-01 에 두 파일 모두 고쳤다)

온라인 버전은 claude.ai 아티팩트로 같은 URL 을 매주 갱신한다.
아티팩트는 **기본이 비공개**이므로 제출 전 공유 설정을 켜고
시크릿 창에서 열리는지 확인할 것.

| 날짜 | 파일 | 무엇 |
|---|---|---|
| 2026-09-04 | `2026-09-04.html` | 1주차 — 주제 확정과 예비 분석 |
| **2026-10-02** | `2026-10-02.html` | 중간 — 4주차가 남긴 숙제 다섯에 답한다 (15장) |
| 2026-10-30 | (예정) | 최종 — 설계 세부가 효과를 가른 과정 |

**구성 원칙.** 교수는 그 주까지의 보고서를 이미 읽는다. 발표는 처음부터
설명하지 않고 **직전 보고서가 남긴 숙제에 답하는** 자리로 쓴다. 10/02 가
4주차 8절의 미해결 다섯 건을 그대로 받아 답하는 구조인 것이 그래서다.
