# 발표 자료 보관

각 발표일의 HTML 을 그대로 보관한다. 브라우저로 열면 바로 발표할 수 있고,
인터넷이 없어도 동작한다(웹폰트만 기본 글꼴로 대체됨).

- `←` `→` 키로 슬라이드 이동
- `Ctrl+P` 로 인쇄하면 슬라이드 한 장이 한 페이지가 된다 (PDF 저장용)

온라인 버전은 claude.ai 아티팩트로 같은 URL 을 매주 갱신한다.
아티팩트는 **기본이 비공개**이므로 제출 전 공유 설정을 켜고
시크릿 창에서 열리는지 확인할 것.
