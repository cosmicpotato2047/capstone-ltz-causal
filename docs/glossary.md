## 1. 기초

### 패널 데이터 · i 와 t

같은 대상을 여러 시점에 걸쳐 반복 관측한 자료. 표기 `X(i,t)` 에서
**i 는 개체(무엇을), t 는 시점(언제)**.

| 자료 구조 | 뜻 |
|---|---|
| 횡단면 | 여러 개체, 한 시점 |
| 시계열 | 한 개체, 여러 시점 |
| **패널** | 여러 개체, 여러 시점 |

**i 가 무엇을 가리키는지는 분석마다 다르다.** 이것이 곧 분석 단위다.

| 분석 | i |
|---|---|
| 반복매매지수 | 그 집 — (단지·전용면적·층) 조합 |
| 본 연구 event study | 개별 거래. 고정효과는 단지(`aptSeq`) 수준 |
| 선행연구 3편 | 법정동 |

### 결과변수 · 처치변수

- **결과변수(outcome)** — 정책이 영향을 미쳤는지 재는 대상. 본 연구의 주 결과변수는
  거래량, 부 결과변수는 ㎡당 가격.
- **처치변수(treatment)** — 정책을 받았는지 여부. 여기서는 "그 시점 그 동이
  토허구역인가"의 0/1.

"주 결과변수를 바꿨다"는 것은 **연구의 중심 질문이 바뀌었다**는 뜻이다.
제목·초록·결론이 거래량 중심으로 서술되고, 가격은 선행연구와 대조하는 보조 위치로
내려간다. → [[0001-주결과변수-거래량]]

### 처치군 · 통제군

- **처치군(treatment group)** — 정책을 받은 집단. 삼성·청담·대치·잠실
- **통제군(control group)** — 정책을 안 받은 집단. 같은 구의 나머지 동

통제군의 역할은 **"처치군에 정책이 없었다면 어떻게 됐을까"의 대역**이다.

### 반사실 (counterfactual)

관측할 수 없는 가정된 상태. "대치동이 규제를 안 받았다면 얼마였을까".

같은 동네를 같은 시점에 규제받은 상태와 안 받은 상태로 동시에 볼 수 없다.
이것을 **인과추론의 근본 문제**라고 한다. 통제군은 그 볼 수 없는 값을 대신
채워 넣는 장치다.

**본 연구의 모든 효과 수치는 반사실 대비다.** 하강률이 아니다.

```
처치동 실제 사후          2,454 만원/㎡
규제가 없었다면(반사실)    2,653 만원/㎡   <- 통제동 상승률을 따랐을 경우
차이                       -199 만원 (-7.5%)

같은 기간 처치동 절대 가격은 +17.5% 상승했다.
```

둘 다 사실이며, 이 구분을 흐리면 선행연구가 빠진 함정에 똑같이 빠진다.
→ [[0006-서술원칙-반사실-명시]]

### 평행추세 (parallel trends)

이중차분의 핵심 가정. **정책이 없었다면 처치군과 통제군이 같은 방향으로
같은 폭만큼 움직였을 것.**

수준이 같을 필요는 없다. 본 연구에서 처치동은 ㎡당 2,087만원, 통제동은
1,534만원으로 36% 차이가 나지만 문제되지 않는다. 첫 번째 차분에서 수준 차이는
사라진다. 요구되는 것은 **변화율의 평행성**이다.

검정 방법은 사건 시점 분석에서 사전 계수가 0 근처에 있는지 보는 것.
본 연구에서 거래량은 통과했고 **가격은 위배**가 확인되었다(k=-5,-4,-3 유의).

## 2. 설계

### 이중차분 (DID, Difference-in-Differences)

차이를 두 번 뺀다.

| ㎡당 평균가(만원) | 사전 | 사후 | ① 시간 차이 |
|---|---|---|---|
| 처치군 | 2,087 | 2,454 | +17.5% |
| 통제군 | 1,534 | 1,950 | +27.1% |
| | | **② 집단 차이** | **-9.5%p** |

- **시간 차분**이 집단 간 고정된 차이를 제거한다 (대치동이 원래 비싼 것)
- **집단 차분**이 모두에게 공통인 시간 효과를 제거한다 (시장 전체 상승)

남는 것이 정책 효과다.

### 삼중차분 (DDD)

이중차분만으로 오염될 때 축을 하나 더 쓴다.

2025년 2월 해제에서 4개 동 아파트 305곳 중 291곳은 풀리고 14곳은 유지되었다.
**유지된 14곳은 무작위가 아니라 재건축 추진 가능성으로 선별**되었으므로,
둘을 단순 비교하면 해제 효과가 아니라 재건축 프리미엄의 차이를 재게 된다.

| | 4개 동 **안** | 4개 동 **밖** |
|---|---|---|
| 일반 단지 | 해제됨 | 규제 없음 |
| 재건축 단지 | 지정 유지 | 규제 없음 |
| 차이 | 해제효과 + 재건축추세 | **재건축추세만** |

```
DDD = [4개 동: 일반Δ - 재건축Δ] - [그 외: 일반Δ - 재건축Δ]
```

이중차분을 두 번 하고 그 둘을 또 뺀다. **이중차분이 "시장 전체 흐름"을
빼준다면, 삼중차분은 거기에 더해 "특정 유형에만 생긴 흐름"까지 빼준다.**

세 번째 축의 비교군을 4개 동 **밖**에서 잡는 이유는 동 내부에 파급효과가
있기 때문이다(아래 SUTVA 항목).

### 사건 시점 분석 (event study)

처치 전후 각 기간별로 효과를 따로 추정해 시간 구조를 본다.
기준 기간(보통 k=-1)의 계수를 0으로 고정하고 나머지를 그에 대한 상대값으로 읽는다.

두 가지를 동시에 한다.
1. **사전 계수** — 평행추세 가정의 검정
2. **사후 계수** — 효과가 언제 시작해 언제 사라지는지

본 연구의 k 는 사건 월(2020년 6월)을 기준으로 3개월씩 끊은 것이다.
달력 분기가 아니다.

| k | 실제 기간 |
|---|---|
| -1 | 2020-03-23 ~ 06-22 |
| 0 | 2020-06-23 ~ 09-22 |
| 1 | 2020-09-23 ~ 12-22 |

**달력 분기가 아니라 효력일에 맞춘 분기다.** 한 달이 23일에 시작해 다음 달
22일에 끝난다. 달력 월로 자르면 지정 전인 6월 1~22일 거래가 k=0 에 섞여
들어간다. 실제로 그렇게 자르고 있었고 k=0 거래의 45.8%가 지정 전이었다.
바로잡은 뒤 k=0 추정치가 크게 커졌다(결정기록 0013).

### 회귀불연속 (RDD)

배정 기준선 양쪽을 비교한다. 기준선 바로 위와 바로 아래는 다른 점이 거의 없는데
처치만 다르므로 비교가 깨끗하다.

본 연구의 확장 과제는 **공간 회귀불연속** — 동 경계로부터의 거리를 배정변수로 쓴다.
경계 양쪽 단지는 학군·교통이 사실상 같은데 규제만 다르다.

### 합성대조군 (SCM, Synthetic Control Method)

여러 비처치 단위에 가중치를 부여해 처치군의 사전 궤적을 가장 잘 재현하는
가상의 통제군을 만든다. 단일 처치 단위에 유용하다.

양지영·정준호(2025)가 사용했다. 다만 **도너풀(가중치를 받는 후보군)에 나중에
처치를 받는 단위가 섞이면 안 된다.** 해당 연구는 압구정·성수1가·성수2가를
도너풀에 넣었는데 이들은 2021년 4월에 토허구역으로 지정되었다.

### 비흡수 처치 (non-absorbing treatment)

처치가 한 번 시작되면 유지되는 것이 **흡수(absorbing)** 처치다.
Callaway & Sant'Anna(2021) 등 표준 추정량이 이 가정에 의존한다.

본 연구의 A그룹은 2025년에 규제 -> 해제 -> 재규제를 겪어 처치 상태가
1 -> 0 -> 1 로 바뀐다. 이 경우 de Chaisemartin & D'Haultfœuille(2020, AER)의
비흡수 처치 추정량을 쓴다. → [[0005-처치역전-추정량]]

## 3. 통제와 추정

### 고정효과 (fixed effects)

관측되지 않지만 시간에 따라 변하지 않는 개체 고유 특성을 통째로 제거하는 방법.
개체마다 더미 변수를 넣는 것과 수학적으로 같다.

**단지 고정효과**를 넣으면 "같은 단지 안에서의 변화"만 보게 된다. 그 단지의
학군·역세권·브랜드 같은 것이 전부 상쇄된다.

본 연구에서 이것이 결과를 크게 바꿨다.

| 단위 고정효과 | 가격효과 추정치 |
|---|---|
| 법정동 | -12.3 ~ -15.8% |
| **단지** | **-6.0 ~ -8.0%** |

분석 창과 통제군 범위를 바꿔도 결과가 거의 안 움직였으나, 고정효과 수준만
2배 차이를 냈다. → [[0003-단지-고정효과]]

### 교대투영 · FWL 정리

Frisch-Waugh-Lovell 정리: 고정효과를 더미로 넣고 회귀하는 것과, 변수들을
그룹 평균으로 뺀 뒤(within-transform) 회귀하는 것이 같은 계수를 준다.

**왜 필요한가.** 단지 3,502개와 월 245개를 더미로 만들면 설계행렬이
472,782 x 3,747 = 17.7억 원소, float64 기준 **약 14GB**가 된다.
일반 회귀 패키지로는 돌아가지 않는다.

고정효과가 둘 이상이면 한 번의 그룹 평균 차감으로 끝나지 않는다.
**교대투영(alternating projections)** — 단지 평균 빼고, 월 평균 빼고,
다시 단지 평균 빼고를 수렴할 때까지 반복한다. 메모리가 상수로 유지된다.

구현: `scripts/lib/econ.py` 의 `demean()`

### 클러스터 표준오차

같은 집단 안의 관측치들이 서로 상관되어 있을 때, 이를 무시하면 표준오차가
과소평가되어 없는 효과를 있다고 말하게 된다.

처치가 동 단위로 배정되므로 **법정동 단위로 클러스터**를 잡는다.

**한계:** 강남·송파만 쓰면 클러스터가 27개뿐이다. 통상 40~50개 이상을 권장하므로
현재 신뢰구간은 다소 낙관적일 수 있다. 통제군 확대 또는 wild bootstrap 으로 대응.

### wild cluster bootstrap

클러스터 수가 적을 때 쓰는 재표본 방법. 클러스터별 잔차의 부호를 무작위로
뒤집어 표본을 여러 번 만들고, 그 분포로 신뢰구간을 구한다.

### 신뢰구간과 유의성

95% 신뢰구간이 0을 포함하지 않으면 "통계적으로 유의하다"고 한다.
본 연구 그림에서 **속이 찬 점은 유의, 빈 점은 비유의**다.

비유의는 "효과가 0이다"가 아니라 **"0과 구분되지 않는다"**는 뜻이다.

## 4. 가격지수

### 반복매매지수 (repeat-sales index)

같은 물건이 두 번 이상 팔린 기록만 써서 만드는 가격지수. Case & Shiller(1987).

**아이디어.** 거래가격을 이렇게 본다.

```
log P(i,t) = α(i) + δ(t) + 잡음
             ^^^^   ^^^^
        그 집 고유   시장 수준
```

같은 집의 두 거래를 빼면

```
log P(i,2018) - log P(i,2015) = δ(2018) - δ(2015) + 잡음
```

**α(i) 가 차분으로 사라진다.** 면적·층·향·학군이 무엇이든 상관없어지고
두 시점의 시장 수준 차이만 남는다. 이런 차분을 모아 시점 더미에 회귀하면
δ(t) 시계열, 곧 가격지수가 나온다.

**흔한 오해.** "같은 집만 추적한다"가 아니다. 쌍마다 다른 집이어도 된다 —
각 쌍 **안에서만** 같으면 된다. 즉 **거래되는 물건이 바뀌어도 상관없게 만든다.**

**우리 데이터.** (단지·전용면적·층) 조합이 2회 이상 거래된 경우를 쌍으로 센다.
95,493개 조합 중 65,035개가 2회 이상 거래되어 **377,289쌍**.

```
CJ나인파크(문배동) 전용 84.98㎡ 21층
  2015-08-29   5.94억
  2018-01-27   8.00억   <- 1쌍, 로그가격차 +0.298
  2019-07-28  10.20억   <- 1쌍, +0.243
  2020-07-01  10.80억   <- 1쌍, +0.057
  2020-08-24  11.46억   <- 1쌍, +0.059
거래 5회 -> 쌍 4개
```

**한계.**
- 두 번 이상 팔린 집만 쓰므로 선택편의가 있다
- 그 사이 리모델링이나 노후화가 있으면 α(i) 불변 가정이 깨진다
- 호수 식별자가 없어 (단지·면적·층)으로 근사한다

### 헤도닉 회귀 (hedonic regression)

가격을 물건의 특성(면적·층·연식·입지)으로 회귀해 특성의 가치를 분해하는 방법.
반복매매와 달리 한 번만 거래된 물건도 쓸 수 있지만, 관측되지 않는 특성이
남는다는 약점이 있다.

두 방법으로 각각 지수를 만들어 대조하는 것이 표준적이다.

## 5. 함정

### 구성 변화 (composition change)

거래되는 물건 자체가 바뀌어 평균값이 움직이는 현상.

본 연구에서 2020.6 지정 후 처치동 표본의 평균 면적이 93.9 -> 88.7㎡ 로 이동했다.
±3개월 구간에서는 411건 -> 50건으로 88% 감소하면서 평균 면적 86.8 -> 80.7㎡,
평균 연식 18.4 -> 20.5년으로 바뀌었다.

**집계 평균만 보면 "같은 집이 싸졌다"와 "다른 집이 팔렸다"를 구분할 수 없다.**
이한웅·이춘원(2025) 사양을 재현했을 때 ±3개월 추정치가 단순 회귀에서는 +8.2%
였으나 단지 고정효과를 넣으면 **-0.1% 로 소멸**했다.

### bad control (나쁜 통제)

처치의 **결과**인 변수를 통제변수로 넣는 것. 정책 효과가 흐르는 경로를 막아
효과를 과소추정한다.

전상현 외(2025)는 거래건수를 통제변수로 포함했다. 거래량 감소는 토허제의
결과이므로 이를 통제하면 안 된다.

| 사양 | 교호항 |
|---|---|
| 거래건수 통제 포함 | -0.045 (p=0.221) |
| 거래건수 통제 제거 | -0.112 (p=0.002) |

### SUTVA 위배 · 파급효과

SUTVA(Stable Unit Treatment Value Assumption): **한 단위의 처치가 다른 단위의
결과에 영향을 주지 않는다**는 가정. 통제군이 처치의 영향을 받으면 깨진다.

2025년 2월 해제 창에서 규제가 유지된 단지 대부분은 거의 반응하지 않았으나
(개포우성1 -1건, 대치우성 0건, 쌍용대치 0건), **잠실주공5단지만 11 -> 32건으로
3배 증가**했다. 같은 동 해제군(리센츠 +62건, 잠실엘스 +46건)의 급등이 규제 유지
단지까지 끌어올린 것으로 보인다.

이 때문에 유지군을 순수 통제군으로 쓸 수 없고, 삼중차분의 비교군을 4개 동
바깥에서 잡아야 한다. 동시에 이것 자체가 연구 질문이 된다(RQ2).

### 사전추세 위배

처치 이전부터 두 집단이 다르게 움직이고 있었던 상태. 평행추세 가정이 깨진다.

본 연구 가격 분석에서 k=-5,-4,-3 계수가 각각 +0.024, +0.033, +0.038 로 모두
유의했다. 사후 하락(-6.8~-8.2%)이 정책 효과인지 기존 추세의 연장인지 분리할 수
없다.

**대응.** 주 결과변수를 거래량으로 변경하고, 가격은 Rambachan & Roth(2023)의
민감도 분석으로 **"사전 추세가 사후에도 일정 수준까지 이어졌다고 가정할 때
효과가 어느 구간에 놓이는가"**를 제시한다.

"방향은 일관되나 **크기는 유보**한다"는 것은 이 뜻이다.

### 선택편의 (selection bias)

분석 표본이 무작위가 아니어서 생기는 편의.

- 반복매매지수: 두 번 이상 거래된 집만 쓴다
- 2025년 유지 14개 단지: 재건축 가능성으로 선별되었다
- 규제지역 지정 자체: 가격이 급등한 곳을 골라 지정한다

마지막 것이 본 연구의 근본적 어려움이며, 동 경계 비교와 사전추세 검정으로
대응한다.
