없어 배제. 토허제를 선택한 이유는 동 단위 지정 + 지정/해제/재지정 반복.

불일치였다 — 「아파트 매매 실거래가 자료」와 「상세 자료」가 별개 서비스이고
활용신청이 개별적이다. `RTMSDataSvcAptTradeDev` 로 해결.

사용자가 Perplexity 로 1차 검증을 수행하고 결과를 반영했다.

**분석.** 2020.6 사건 시점 분석, 12개 사양 강건성, 선행연구 재현.

**인프라.** git 저장소 개설 및 공개 push, 기록 체계 구축.

## 발견

1. **가격의 사전추세 위배.** 이걸 먼저 확인하지 않고 DID 만 돌렸다면
   심사에서 무너졌을 것. 주 결과변수를 거래량으로 변경([[0001]]).

2. **선행연구 재현 성공.** 전상현 외(2025)의 675개 격자를 재구성하니 빈 셀
   31개가 전부 통제동에서 발생. 0으로 코딩하면 논문의 네 계수와 R2 가 근사
   재현되고, 정상 처리하면 부호가 반전된다.

3. **양지영·정준호(2025)의 도너 풀 오염.** 대조군 15개 동에 압구정·성수1가·
   성수2가가 포함되는데, 이들은 2021.4.27 토허 지정 대상이다. 연구기간
   마지막 13개월 동안 대조군의 20%가 처치를 받은 상태.

4. **잠실주공5단지 이상치.** 규제 유지 단지인데 해제 창에서 11 -> 32건 증가.
   같은 동 해제군의 파급효과로 보이며, SUTVA 위배이자 새 연구질문.
