# 설계 결정 기록

하나의 결정 = 하나의 파일. 형식:

```
# NNNN. 제목
- 일자 / 상태(확정|잠정|폐기)
## 맥락      무엇이 문제였나
## 결정      무엇으로 정했나
## 근거      왜. 가능하면 수치로
## 대안      검토했으나 택하지 않은 것과 그 이유
## 영향      이 결정이 무엇을 바꾸는가
```

작업 일지(`../journal/`)는 시간이 지나면 가치가 떨어지지만,
이 기록은 논문 방법론 절로 그대로 옮겨진다.
