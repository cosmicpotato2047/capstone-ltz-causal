# 0003. 단지(aptSeq) 고정효과를 기본 사양으로 채택

2026-09-03 · 확정

## 맥락
선행연구 3편은 모두 동 단위 집계자료를 쓴다. 우리도 동 고정효과로 갈지,
단지 고정효과까지 내려갈지 결정이 필요했다.

## 결정
단지(aptSeq) x 계약월 양방향 고정효과를 기본 사양으로 한다.
면적·층·연식을 추가 통제한다.

## 근거
12개 사양 비교에서 단위 고정효과 수준이 결과 크기를 두 배 갈랐다.

| 단위 FE | 가격효과 |
|---|---|
| 법정동 | -12.3 ~ -15.8% |
| 단지   | -6.0 ~ -8.0% |

분석 창(±12/24/36개월)과 통제군 범위(2개구/8개구)는 거의 영향이 없었다.
즉 **결과를 좌우하는 유일한 설계 선택이 단위 고정효과**다.

토허제 하에서 거래량이 60% 감소하면 거래되는 물건의 구성이 바뀐다.
실제로 처치동 사후 표본의 평균 면적이 93.9 -> 88.7㎡ 로 이동했다.
단지 고정효과 없이는 이 구성 변화가 가격 효과로 오인된다.

## 대안
- 동 고정효과: 선행연구와 비교가 쉽지만 구성 변화를 통제하지 못함.
  -> 대조 목적으로 부표에 함께 보고하는 것으로 절충.

## 영향
- aptSeq 필드가 필수. 「상세 자료」 API 를 써야 하는 이유이기도 하다.
- 반복매매지수 구축의 전제이기도 함 (동일 단지·면적·층 조합 재거래 25.4만 쌍).
- 차별점 매트릭스의 핵심 축.
