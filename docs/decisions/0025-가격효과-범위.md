# 0025. 가격 효과는 −4 ~ −7% 로 모인다 — 다만 합성대조군으로는 확인되지 않는다

2026-09-23 · 확정

재현: `python scripts/08_hedonic.py`
(`output/results/08_hedonic.json`, `output/figures/08_hedonic.png`,
`data/processed/hedonic_index.csv`)

## 맥락

[[0024-파급효과-기준점]] 이 숙제를 남겼다. 지정 전 ㎡당가를 처치동 범위에 맞춘
표본에서 처치동 가격 효과가 −9.7% 에서 **−2.1%(p=0.270)** 로 약해졌다. 처치
효과인지 가격대 효과인지 가르지 못한 채 백로그 8(헤도닉)·11(Honest DiD)로
넘겼다. 여기는 그 가운데 8 이다.

동시에 백로그 8 자체의 목적이 있다. [[0018-반복매매지수]] 는 같은 집만 보므로
구성 변화에 강하지만 **두 번 팔린 집만** 쓴다(선택편의). 헤도닉은 모든 거래를
쓰되 관측되는 특성만 통제한다. 둘이 같은 이야기를 하면 서로를 떠받친다.

## 방법

**구성 통제의 사다리**로 지수 다섯을 같은 자료로 짓는다. 아래로 갈수록 더
많은 것을 고정한다.

| 지수 | 무엇을 고정하나 |
|---|---|
| 중위가 (총액) | 아무것도 |
| 중위가 (㎡당) | 물건의 크기 |
| 헤도닉 | 면적과 층 |
| 헤도닉 + 단지 | 거기에 단지의 질까지 |
| 반복매매 | 같은 집 |

헤도닉은 `log(㎡당가) ~ 월더미 + log면적 + log면적² + 층 구간더미` 다. 층은
1~2 / 3~5 / 6~10 / 11~15 / 16층 이상으로 끊고 6~10층을 기준으로 둔다. **연식은
넣지 않는다** — 단지 고정효과 아래에서 연식은 시간의 일차함수라 월 고정효과와
공선이다.

**통제 격자**로 이중차분을 네 칸씩 두 통제군에 건다. 창은 지정 전후 12개월이다.

**가격 합성대조군.** 공통지지가 손으로 가격 구간을 자르는 것이라면, 합성대조군은
사전 궤적이 맞도록 **자료가 기증자 동의 가중치를 직접 고른다**. 결과변수는 단지
고정효과와 특성을 걷어낸 가격 잔차의 동·월 평균이고, 수준이 아니라 사전 평균
대비 변화를 맞춘다([[0017-합성대조군]] 과 같은 조작).

> **기증자에서 맞닿은 동 14개를 뺀다.** 0024 에서 그 동들의 가격이 19개 구
> 대비 −5.0% 움직였다. 파급을 받은 동을 통제군에 넣으면 효과가 0 쪽으로 끌린다.
> 실제로 빼기 전 −3.5%, 빼고 나서 −5.1% 다.

## 결과

### 서로 다른 두 방법이 같은 답을 낸다

지정 후 12개월 평균, 처치동 ÷ 통제동 비의 변화다.

| 지수 | 변화 |
|---|---|
| 중위가 (총액) | −10.1% |
| 중위가 (㎡당) | −12.5% |
| 헤도닉 | −11.1% |
| **헤도닉 + 단지** | **−5.9%** |
| **반복매매** | **−6.0%** |

**헤도닉+단지와 반복매매가 −5.9% 와 −6.0% 로 맞는다.** 한쪽은 모든 거래를 쓰고
특성으로 맞추며, 다른 쪽은 같은 집만 본다. **통제동 집합은 07 과 맞춰 강남·송파
비처치 전부로 두었다** — 지수끼리 견주려면 같은 동이어야 한다. 오염 6개 동을
빼면 헤도닉+단지가 −5.8% 로 0.1%포인트 움직인다. 자료도 가정도 다른 두 방법이 같은
숫자를 낸다는 것은 구성 변화가 결론을 만들지 않았다는 뜻이다.

### 0018 의 11포인트를 분해했다

0018 은 처치동 월평균 전용면적이 103.4㎡ 로 튄 2020-09 에 중위가 지수 170.5,
반복매매 159.4 로 **11포인트 벌어진다**고 적었다. 그 사이를 채웠다.

| 지수 | 2020-09 |
|---|---|
| 중위가 (총액) | 170.5 |
| 중위가 (㎡당) | 160.0 |
| 헤도닉 | 143.5 |
| 헤도닉 + 단지 | 156.7 |
| 반복매매 | 159.4 |

**11.1포인트 중 10.5포인트가 '총액에서 ㎡당가로 바꾸는 것' 하나로 걷힌다.**
중위가의 부풀림은 사실상 "큰 물건이 팔렸다" 하나였다. 헤도닉(특성만)이 143.5 로
오히려 낮은 것은 단지 구성이 바뀐 것까지 잡지 못해서다 — 단지 고정효과를 넣으면
156.7 로 반복매매에 붙는다.

### 통제 격자 — 0024 의 −2.1% 가 어느 칸이었나

| 통제군 | ① 단지·월 FE | ② + 면적·층 | ③ ① + 공통지지 | ④ ② + 공통지지 |
|---|---|---|---|---|
| 강남·송파 통제동 | −5.5% (0.028) | −6.7% (0.001) | −4.2% (0.065) | −5.9% (0.001) |
| 서울 나머지 19개 구 | −9.8% (0.000) | −10.7% (0.000) | **−2.1% (0.270)** | −4.2% (0.001) |

**0024 의 −2.1% 는 이 격자의 한 칸이고, 특성을 통제하지 않은 칸이다.** 같은
표본에 면적·층을 넣으면 −4.2%(p=0.001) 가 된다. 나머지 일곱 칸은 −4.2 ~ −10.7%
사이에 있다.

읽는 법은 이렇다. **가격대를 맞추는 것이 결과를 크게 바꾸는 쪽은 서울 통제군뿐이다**
(−9.8% → −2.1%). 강남·송파 통제동은 이미 비슷한 가격대라 바뀔 것이 없다
(−5.5% → −4.2%). 즉 0024 가 의심한 '고가 단지가 그 시기에 뒤처졌다'는 효과는
**실재하지만, 그것을 걷어내도 −4% 안팎이 남는다.**

### 가격 합성대조군은 확인해 주지 못한다

| | 값 |
|---|---|
| 기증자 | 46개 법정동 (창 안 지정 74개 + 맞닿은 동 14개 제외) |
| 사전 RMSPE | 0.0178 |
| 사후 RMSPE | 0.0762 (비 4.28) |
| 지정 후 12개월 평균 격차 | **−5.1%** |
| 사후 전체 평균 격차 | −6.4% |
| 배치 위약 46개 중 오차비가 더 큰 것 | **23개 → 경험적 p = 0.511** |

**점추정은 −5.1% 로 위 격자와 같은 자리에 떨어지는데, 위약과 구분되지 않는다.**
거래량에 같은 방법을 걸었을 때는 경험적 p 가 0.007 이었다([[0017-합성대조군]]).
방법이 아니라 **결과변수가 문제다.** 동·월 가격 잔차 평균은 거래 건수보다 훨씬
시끄럽고, 기증자 절반이 사후에 사전만큼 잘 안 맞는다.

## 결정

**1. 가격 효과를 −4 ~ −7% 범위로 보고한다.** 여덟 칸 중 가격대를 맞춘 네 칸이
−2.1 ~ −5.9%, 맞추지 않은 네 칸이 −5.5 ~ −10.7% 다. 통제군과 가격대를 함께
고려한 중심은 −4 ~ −7% 이고, 여기에 헤도닉+단지(−5.9%)·반복매매(−6.0%)·
합성대조군 점추정(−5.1%)이 모두 들어온다.

**2. 그래도 인과로 단정하지 않는다.** [[0001-주결과변수-거래량]] 의 판단을 뒤집지
않는다. 이유 둘이다.

- **사전 추세 위배가 그대로 있다.** 가격은 k=−5·−4·−3 에서 유의했다. 이 결정은
  구성과 가격대를 걷어냈을 뿐 사전 추세를 다루지 않았다. 그건 백로그 11 이다.
- **합성대조군이 확인해 주지 못한다.** 점추정은 맞지만 위약과 구분되지 않는다.

**3. 연구의 뼈대 '가격은 잡혔나' 칸을 고쳐 쓴다.** "−8%" 하나가 아니라
"−4 ~ −7% 범위, 인과로는 단정 못 함"으로 한다.

**4. [[0024-파급효과-기준점]] 의 고리 이름을 정정한다.** 'R4 나머지 17개 구'는
**19개 구**다. 서초구와 용산구가 어느 고리에도 명시되지 않아 기본값으로 들어간다.
2020년에 미처치이고 처치동과 맞닿지도 않아 통제군으로 쓰는 것 자체는 맞다.
오히려 가격대가 가장 비슷한 동들이라 공통지지에서 중요하다. **수치는 그대로이고
이름만 틀렸다.**

## 앞뒤 작업과의 관계

**0024 의 숙제를 절반 받았다.** 가격대와 처치를 가르는 일은 여기서 했고, 사전
추세는 백로그 11(Honest DiD)이 받는다.

**0018 을 떠받친다.** 반복매매지수가 선택편의 때문에 틀렸을 가능성을 헤도닉이
독립적으로 배제했다. 두 지수가 −5.9% 와 −6.0% 로 맞는다.

**앞으로 쓸 곳.**

- **백로그 11 Honest DiD (M3)** — 사전 추세가 사후에도 이어졌다고 가정할 때
  이 −4 ~ −7% 가 어느 구간으로 넓어지는지.
- **백로그 5b 사양 곡선** — 이 격자 여덟 칸이 곡선의 점이 된다.
- **최종 보고서** — 거래량은 단정하고 가격은 범위로 쓴다는 구도를 여기서 확정한다.

## 한계

- **헤도닉의 특성이 면적과 층뿐이다.** 향·동·조망은 자료에 없다. 단지 고정효과가
  단지 수준의 것은 흡수하지만 같은 단지 안의 차이는 남는다.
- **헤도닉 지수는 지수마다 표본이 다르다.** 반복매매는 두 번 팔린 집만, 헤도닉은
  모든 거래를 쓴다. 둘이 맞는다는 것이 둘 다 옳다는 뜻은 아니다.
- **합성대조군의 기증자가 46개뿐이다.** 매달 거래가 있는 동만 남기면 이만큼이다.
  거래량 합성대조군(151개)보다 작다. 검정력이 낮다.
- **사전 추세 위배를 다루지 않았다.** 이 결정의 모든 숫자는 평행추세를 가정한다.
- 공통지지 구간(1,142~2,649만원/㎡)은 처치동 단지의 5~95%다. 문턱을 옮기면
  숫자가 조금 움직인다. 민감도는 백로그 5b 에서 곡선으로 낸다.
