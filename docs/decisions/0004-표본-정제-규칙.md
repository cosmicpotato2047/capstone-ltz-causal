# 0004. 취소거래 제외 및 신고지연 절단

2026-09-03 · 확정

## 결정
1. `cdealType` = 'O' 인 거래 해제(취소) 건을 표본에서 제외한다.
2. 분석 구간의 끝을 2026-05 로 절단한다.

## 근거
**취소거래.** 전체 47.7만 건 중 4,285건(1.3%). 신고 후 취소된 거래에는
시세 조작 목적의 허위 신고가 포함될 수 있다. 규제 시점 전후로 집중될 경우
추정치를 위로 편향시킨다. 규제 효과 분석에서는 특히 위험하다.

**신고지연.** 신고기한이 계약일로부터 30일이라 최근 월이 과소집계된다.
2026-05 1,826건 -> 2026-06 871 -> 2026-07 763 -> 2026-08 266 으로 급감.
보수적으로 2026-05 까지만 사용한다.

## 영향
- 취소거래의 시점별 분포 자체가 별도 분석 가치가 있다. 규제 직후에 몰린다면
  그 자체가 정책 반응이다. (2주차 이후 확인)
- 데이터 스냅샷 시점(2026-09-03)을 명시해야 한다. 실거래 자료는 소급 갱신되므로
  다른 시점에 수집하면 결과가 달라진다.
