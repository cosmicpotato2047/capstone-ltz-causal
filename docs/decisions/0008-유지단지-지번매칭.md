# 0008. 지정 유지 단지를 단지명이 아니라 지번으로 확정한다

2026-09-07 · 확정

## 맥락

2025년 2월 부분 해제 시 지정이 유지된 재건축 단지의 수가 자료마다 달랐다.

| 자료 | 수 |
|---|---|
| 서울시 설명자료 | 14곳 |
| 공고 2025-1831 게시본 표기 | 13행 |
| '우성1·2·3차' 를 분리하면 | 15개 |

확정 전까지는 좁은 정의와 넓은 정의를 병행해 강건성으로 보고할 계획이었다.

## 결정

서울특별시 공고 제2025-497호(2025-02-13) 원문의 별표와 지형도면에서 **지번**을
추출해 실거래 자료의 `bonbun`/`bubun` 와 매칭한다. 결과를
`scripts/lib/policy.py` 의 `KEPT_2025` 에 **aptSeq 집합**으로 고정한다.

## 근거

원문에 14개 항목이 지번과 함께 명시되어 있다.

| 지번 | 단지 | 실거래 aptSeq |
|---|---|---|
| 강남 대치동 503 | 개포우성1차 | 11680-372 |
| 강남 대치동 500 | 개포우성2차 | 11680-216 |
| 강남 대치동 506 | 선경 | 11680-211, **11680-3559** |
| 강남 대치동 511 | 한보미도맨션 | 11680-222, **11680-481** |
| 강남 대치동 66 | 쌍용1차 | 11680-373 |
| 강남 대치동 65 | 쌍용2차 | 11680-214 |
| 강남 대치동 63 | 우성1차 | 11680-217 |
| 강남 대치동 316 | 은마 | 11680-218 |
| 강남 삼성동 53-2 | 진흥 | 11680-187 |
| 강남 청담동 75-1 | 현대1차 | 11680-82 |
| 송파 잠실동 27 | 주공5단지 | 11710-164 |
| 송파 잠실동 101-1 | 우성1·2·3차 | 11710-159 |
| 송파 잠실동 320 | 우성4차 | 11710-160 |
| 송파 잠실동 86 | 아시아선수촌 | 11710-158 |

**공고 14개 항목 = 실거래 16개 aptSeq.** 선경과 한보미도맨션이 실거래 자료에서
1차/2차로 나뉘기 때문이다. 지번이 같으므로 둘 다 유지 대상이다.
미매칭 0건.

## 이 방식이 아니었다면 틀렸을 것

단지명 문자열로 매칭했을 때의 오류 두 건이 드러났다.

- **`현대1`(거래 92건)을 유지군에 넣었으나 오류.** 공고상 청담동 75-1 은
  실거래 자료에서 `현대아파트(75-1)`(거래 35건)이다. `현대1` 은 다른 단지다.
- **`선경3차` 를 넓은 정의에 포함했으나 오류.** 공고 지번(대치동 506)에 없다.
  실제로는 해제군이다.

지번은 공고의 법적 기준이고 단지명은 표기 관행이다. **행정 자료와 거래 자료를
잇는 키는 이름이 아니라 지번이어야 한다.**

## 영향

- narrow/broad 병행이 불필요해졌다. 처치 정의가 하나로 확정된다.
- 해제창 39일 재계산: 해제군 104 -> 577건, 유지군 43 -> 92건 (기존과 거의 동일)
- 같은 방식을 2020년 지정 범위 확정에도 적용할 수 있다.
  공고 2020-1832 의 토지조서를 확보하면 필지 단위 처치 배정이 가능하다.

[[0003-단지-고정효과]] 와 함께 읽을 것. aptSeq 가 없었다면 이 매칭도 불가능했다.
