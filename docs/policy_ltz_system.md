# 토지거래허가 제도 — 제도 자체의 정리

출처: [서울부동산정보광장 토지거래허가 제도 안내](https://land.seoul.go.kr/land/other/contractGuide.do)
확인일 2026-09-07

---

## 1. 근거와 지정

| | |
|---|---|
| 근거 법령 | 국토의 계획 및 이용에 관한 법률, 농지법, 부동산등기특별조치법 |
| **지정권자** | **국토교통부장관, 서울특별시장** — 두 주체가 각각 지정한다 |
| 지정기간 | 5년 이내 |

지정권자가 둘이라는 점이 자료 수집에 직접 영향을 준다. 서울시장 지정분은
**서울시보**에, 국토부장관 지정분은 **대한민국 전자관보**에 실린다.

## 2. 허가 대상 면적 — 기본값과 특례

도시지역의 법정 기본 기준은 다음과 같다.

| 용도지역 | 기본 기준 |
|---|---|
| 주거지역 | 60㎡ 초과 |
| 상업지역 | 150㎡ 초과 |
| 공업지역 | 150㎡ 초과 |
| 녹지지역 | 200㎡ 초과 |
| 용도 미지정 | 60㎡ 초과 |

**그러나 지정 시 기준면적의 10%~300% 범위에서 별도로 정할 수 있다.**
실제 지정 공고는 이 특례를 자주 쓴다.

| 지정 | 주거지역 기준 | 기본값 대비 |
|---|---|---|
| 2020.6 국제교류복합지구 | 18㎡ 초과 | 30% |
| 2022 이후 | 6㎡ 초과 | **10% — 하한** |
| 2025.3 강남3구·용산 | 6㎡ 초과 | 10% |

**기준을 하한까지 낮춘 것은 사실상 전수 포함을 의도한 설계다.**
다만 2020년의 18㎡는 실제로 일부 물건을 배제했을 수 있다.

**중요:** 이 면적은 아파트의 전용면적이 아니라 **거래 대상 토지(대지권 지분)**의
면적이다. 우리 실거래 자료에는 대지권 면적이 없으므로 처치 정의에 직접 반영할 수
없다. 한계로 명시한다.

## 3. 허가 대상 행위

허가구역 내 토지의 **소유권 또는 지상권을 이전·설정하는 계약**.
거래당사자가 공동 신청하며, 허가증은 신청 후 15일 이내 교부.

## 4. 이용 의무기간 — 토허제의 실질적 구속력

| 취득 목적 | 의무기간 |
|---|---|
| 농업용 | 2년 |
| 임업용 | 3년 (생산물 없으면 5년) |
| **주거용** | **2년** |
| 개발·사업용 | 4년 |
| 기타(현상보존 등) | 5년 |

**주거용 2년 실거주 의무가 아파트 시장에 대한 핵심 제약이다.**
전세를 끼고 사는 갭투자가 원천 차단된다.

이것이 본 연구의 메커니즘 가설과 직결된다. 토허제는 가격 상한을 정하는 제도가
아니라 **거래에 절차 비용을 부과하고 특정 매수 유형(갭투자)을 배제하는** 제도다.

## 5. 위반 시 제재

| 위반 | 제재 |
|---|---|
| 허가 미신청 거래 | 2년 이하 징역 또는 **토지가격의 30% 이하 벌금** |
| 용도 미이용 | 3개월 이행기간 부여 후 **취득가액의 10% 범위 내 이행강제금** |

제재가 가볍지 않다. 우회 유인은 있으나 비용이 크다.

## 6. 허가 절차

```
허가신청서 제출 → 관련 부서 협의·현장조사 → 허가/불허가 결정
                                              │
                              (불허 시) 1개월 내 이의신청
                                              ↓
                                     도시계획위원회 심의
                                              ↓
                                         허가증 교부
```

신청부터 교부까지 15일. **이 절차 자체가 거래 마찰이며, 본 연구가 측정하는
거래량 효과의 직접적 원인이다.**

## 7. 연구 설계와의 연결

| 제도 요소 | 본 연구에서의 함의 |
|---|---|
| 지정권자 이원화 | 서울시보 + 전자관보 두 경로를 모두 확인해야 한다 |
| 면적 기준 특례 | 2020년 18㎡ vs 2022년 이후 6㎡. 처치 강도가 시기별로 다르다 |
| 대지권 기준 | 실거래 자료에 없다. 처치 정의를 전용면적으로 대리할 수 없다 |
| 2년 실거주 의무 | 갭투자 차단 → 대출 노출도별 효과 이질성의 근거 |
| 15일 심사 | 거래 마찰의 실체. 거래량이 1차 반응인 이유 |
| 5년 이내 지정기간 | 재지정이 반복된다. 처치 연속성을 공고로 확인해야 한다 |
