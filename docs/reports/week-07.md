## 요약

**분석은 끝났고 이번 주는 1층(시스템)을 닫는 주였다.** 결과는 넷이다.

1. **클린 환경 재현에서 `requirements.txt` 의 구멍 둘을 찾았다.** `shapely` 와 `markdown` 이 빠져 있어 새 가상환경에서는 12단계에서 멈춘다. 작업 환경에는 다른 경로로 깔려 있어 몇 주 동안 드러나지 않았다.
2. **고친 뒤 전 단계가 돌았고 `output/results/*.json` 25개가 바이트 단위로 같았다.** 재현이 확인됐다(백로그 15).
3. **결과 대시보드를 만들었다**(백로그 20). 숫자 24개마다 **어느 결정기록에서 나왔는지와 어떻게 다시 돌리는지**를 붙인다. `output/results/*.json` 에서 생성하므로 손으로 적지 않는다.
4. **의존 점검기(`check_deps.py`)를 만들어 파이프라인에 넣었다.** 같은 종류의 구멍이 다시 생기면 그 자리에서 잡힌다.

그 밖에 **14b 를 닫고**, 2주 낡았던 `framing.md` 를 갱신하고, **최종 보고서 뼈대**를 잡았다.

## 1. 클린 환경 재현 (백로그 15)

### 1.1 절차

| 단계 | |
|---|---|
| 1 | 새 폴더에 `git clone` |
| 2 | 새 가상환경 + `pip install -r requirements.txt` (약 12분) |
| 3 | `data/raw` 를 접합(junction)으로 연결 — **재수집하면 안 된다** |
| 4 | `python run_all.py` |
| 5 | `output/results/*.json` 을 원본과 해시 대조 |

**3번이 중요하다.** 실거래 자료는 취소와 지연신고로 **소급 갱신**되므로 `--collect` 로 다시 받으면 같은 결과가 나오지 않는다. 재현은 **같은 스냅샷 위에서** 하는 것이다.

### 1.2 멈췄다 — shapely 가 없다

```
[FAIL] [12] scripts/12_spillover.py (7.9초)
  File "scripts/lib/geo.py", line 138, in touching
    from shapely.ops import unary_union
ModuleNotFoundError: No module named 'shapely'
```

**`requirements.txt` 에 `shapely` 가 없었다.** `lib/geo.py` 가 법정동 경계로 맞닿은 동을 찾을 때(백로그 12, [0024](../decisions/0024-파급효과-기준점.md)) 쓰는데, 그때 목록에 안 넣었다.

이어서 `markdown` 도 빠진 것을 찾았다. `render_report.py` 가 쓰는데 파이프라인이 12단계에서 멈춰 거기까지 가지 못했을 뿐이다.

> **받는 사람만 겪고 만드는 사람은 못 보는 고장이다.** 내 환경에는 둘 다 다른 경로로 깔려 있었다. 백로그 15 를 건 이유가 정확히 이것이다.

### 1.3 고친 뒤 — 바이트 단위로 같다

| | |
|---|---|
| 전 단계 | **성공** |
| 소요 | 약 **21분** |
| `output/results/*.json` | **25개 전부 바이트 동일** |

### 1.4 덤으로 걸린 것 둘

**(가) 윈도 긴 경로 한계.** 처음에 깊은 임시 폴더(137자)에 clone 했더니 `statsmodels` 의 시험 자료 경로가 **266자**가 되어 설치가 깨졌다. 윈도 기본 한계는 **260자**이고 이 기계는 긴 경로 지원이 꺼져 있다(`LongPathsEnabled = 0`).

고약한 점은 **pip 가 오류를 내고도 나머지는 설치했다**는 것이다. `statsmodels` 만 빠진 채로 끝난다. 짧은 경로에서 다시 하니 8개 전부 깔렸다.

**(나) 저장소가 무겁다.** `.git` 이 **936MB** 다. 그림을 매번 커밋해 이력이 쌓였다. clone 은 10초면 되지만(로컬) 원격에서는 부담이다. **지금 고치지 않는다** — 이력을 다시 쓰는 일이라 남은 5주에 할 작업이 아니다. 한계로 적는다.

### 1.5 README 에 반영했다

재현 절차에 **「클린 환경에서 재현할 때」** 절을 더해 위 셋을 적었다.

## 2. 의존 점검기 (`check_deps.py`)

같은 구멍이 다시 생기지 않게 만들었다. `check_numbers.py`(문서 수치)·`check_stale.py`(고아 산출물)와 같은 계열이다.

| | |
|---|---|
| 하는 일 | `scripts/**/*.py` 를 **AST 로 훑어** 실제 import 와 `requirements.txt` 를 맞춘다 |
| 왜 AST 인가 | `lib/geo.py` 의 shapely 처럼 **함수 안에서 늦게** import 하는 것도 잡아야 한다 |
| 간접 의존 | `pyarrow` 는 직접 import 하지 않지만 pandas 가 parquet 에 쓴다 — 이유와 함께 따로 적는다 |
| 등록 | 전체 재실행의 **C3** 단계 |

```
의존 점검 — 스크립트가 쓰는 외부 패키지 9개 · requirements.txt 10줄
  빠진 것 없음. 쓰는 것이 전부 적혀 있다.
통과 — requirements.txt 가 실제 import 와 맞는다.
```

## 3. 결과 대시보드 (백로그 20)

`output/dashboard.html` · [index](../../index.html) 에서 연다.

### 3.1 무엇을 푸는가

결과가 **결정기록 31편 · 주차 보고서 7편 · JSON 25개**에 흩어져 있다. "이 숫자 어디서 나왔나"를 묻는 사람(심사위원, 그리고 석 달 뒤의 나)이 매번 저장소를 뒤져야 한다.

**숫자마다 세 가지를 붙인다** — 어느 결정기록인지, 어느 스크립트가 만들었는지, 어떻게 다시 돌리는지. **숫자의 계보를 보이는 것**이 목적이다.

| 묶음 | 지표 |
|---|---|
| 얼마나 줄었나 | 직후 −79.8% · 무작위 1/17,550 · 합성대조군 −71.0% · 사양 곡선 100% |
| 언제까지 갔나 | 24개월 −33.5% · 붕괴값 0.05 |
| 누구에게 달랐나 | 2022 강화 −33.2% · 2021 위약 −8.1% · 2025 재지정 −71.5% |
| 어디로 번졌나 | 유지군 −26.5% · 처치동 기준 +115.5% · 서울 기준 −9.0% |
| 가격은 잡혔나 | 반복매매 −6.0% · 헤도닉+단지 −5.9% · 붕괴값 0.22 · SCM p 0.511 |
| 믿어도 되는가 | B−A +8.7% · 무작위 3,576/5,000 · 가격 음수 80% · 취소 +0.3%p |
| 자료 | 표본 472,782 · 서울 1,407,186 · 단지 3,502 · 반복매매 377,289 |

### 3.2 손으로 적지 않는다

`output/results/*.json` 에서 읽어 쓴다. 적는 것은 **어디서 꺼낼지와 어떻게 읽을지**뿐이다. 분석을 다시 돌리면 이 페이지도 따라 바뀐다 — [0007](../decisions/0007-문서유형별-수치기록.md) 이 "현재 값의 출처는 하나"라고 한 원칙을 화면에도 적용했다.

**경로를 라벨로 쓴다.**

```
거래량[k=0].effect_pct
지수_사다리[지수=반복매매].변화_pct
나_2022_기준강화[기준_㎡=40.0].소형효과_pct
```

번호(`[1]`)는 스크립트가 줄 순서를 바꾸면 **조용히 다른 값**을 가리킨다. 라벨은 그때 **'없음'으로 드러난다.** 만들면서 실제로 12개가 '없음'으로 떴고(내가 JSON 구조를 잘못 짐작했다) 전부 고쳐 **24개 중 0개**가 됐다.

## 4. 백로그 14b 를 닫았다

[0007](../decisions/0007-문서유형별-수치기록.md) 이 **"M3 시점에 재검토한다"**고 적어 둔 항목이다. M3 는 10/01 에 끝났으므로 약속한 시점이다.

**하지 않기로 닫았다.** 이유 셋을 0007 에 적었다.

1. **검사 쪽이 그 사이 넓어졌다.** 10/01 에 결정기록까지 검사 대상에 넣었고, 고아 산출물·링크·의존까지 본다. 마커가 막으려던 구멍의 대부분을 이미 막는다.
2. **지금이 문장을 가장 많이 고치는 시기다.** 최종 보고서와 10/30 발표 자료를 쓰는 4주 동안 마커를 심으면 부담이 가장 크다.
3. **고치는 쪽이 아니라 잡는 쪽으로 간다.** 남은 4주에 새 장치를 들이는 비용이 이득보다 크다.

**다시 열 조건도 적었다** — 다음 학기 이후로 이어 쓰거나, 같은 숫자를 세 곳 넘게 손으로 옮기게 되면.

## 8. 미해결 사항과 다음 작업

**미해결**

- **저장소 `.git` 이 936MB 다.** 그림을 매번 커밋해 이력이 쌓였다. 이력을 다시 쓰는 일이라 남은 5주에 하지 않는다.
- **원자료는 재현할 수 없다.** 소급 갱신되므로 `--collect` 로 다시 받으면 다른 자료가 온다. 스냅샷을 옮기는 것이 유일한 길이고 README 에 적었다.
- **대시보드가 추가 분석을 자동으로 따라가지 않는다.** 새 지표는 `ROWS` 에 손으로 한 줄 적어야 한다. 다만 **값은 손으로 적지 않는다.**
- 지난주까지의 미해결(지속 기간·가격의 크기·해제와 부과의 대칭·거래 주체)은 그대로다.
